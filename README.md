# Antonella's School Dashboard 🦋

A magical butterfly-themed school dashboard for Antonella — 6th grade at
Saint Paul's School, Kensington, CT.

**Live site:** https://mvcartiera22-code.github.io/antonella-dashboard/

## What it does

- ⭐ Star points for daily responsibilities and finished homework
- 📝 Homework & test tracker (finished items disappear the next day)
- 📅 Real calendar with activity dots (BJJ, Theater, Bass Guitar) and the
  Dec 18 birthday
- 🎂 Live birthday countdown
- 💾 Everything saves automatically on the device; Backup/Restore buttons
  keep a safety copy in Google Drive

## How it's built

One single `index.html` file — no server, no accounts, no installs.
All data lives in the browser's localStorage on each device.

To update the site: replace `index.html` with the new version and commit.
Saved data survives updates because it's tied to the web address, not the file.
